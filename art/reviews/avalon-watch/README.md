# Сверка «Береговой вахты» с игрой

[Открыть попарную галерею](index.html) · [Надпись до и после правки](lettering.png) · [Исходные макеты](../../concepts/avalon-watch/index.html)

Слева на каждом листе утверждённая композиция, справа кадр Chrome. Размеры сторон совпадают до пикселя. Галерея содержит 40 игровых состояний и контрольный кадр главного меню для каждого формата. ПК снят при 1280×720, телефоны при 360×640 и 720×360. Эмуляция телефона включает касания и DPR 2. Игровой кадр экспортируется в CSS-пикселях. Полноразмерные PNG открываются щелчком. Подписи в галерее русские, размер текста обычный.

У надписи «Новая игра» в одинаковом фрагменте осталось восемь цветов, как в макете. [Увеличение заголовка](lettering.png)

## Какие состояния сняты

Для подготовки, каталога, линз, способностей, разведки и боя третьей ночи использован один профиль с пушкой №7, барьером №8 и выбранной Вспышкой. Положение существ, заряды, здоровье, волна и таймер берутся из идущего боя. Для Стража снято предупреждение о реальном ударе. Листы выбора главы, покупки и коллекции сняты с выбранным пунктом и прогрессом близкими к показанным в макете. В результатах видна отдельная строка доплаты за первую победу. Макеты объединяют её с основной выплатой.

Хроника, сюжетные главы, покупки и устройства открывались в интерфейсе игры с изолированным хранилищем. Финальная глава использует заранее развитый профиль. Доска испытаний и отдельный небольшой кошелёк доступны в докампанейском прототипе. Ошибки вызваны отказом тестовой записи. Подтверждение добровольной награды снято на предусмотренном разработческом стенде.

## Повтор съёмки

Понадобятся установленный Chrome, Playwright и Python с Pillow. Путь к внешнему Playwright задаётся через `LIGHTHOUSE_PLAYWRIGHT_PATH`. Браузерные сценарии запускают локальный Vite и сохраняют исходные кадры в `test-results/watch-art-audit/`.

```powershell
$env:WATCH_ART_PASS = 'after'
node tools/browser/verify-avalon-watch.cjs
node tools/browser/capture-watch-world.cjs
node tools/browser/capture-watch-workshop.cjs
python tools/assets/compare-avalon-watch.py
```

Последняя команда проверяет наличие успешного прогона всех 12 конфигураций и размеры каждой пары. Исторический фрагмент заголовка до исправления сохранён в [before-title.png](before-title.png).
