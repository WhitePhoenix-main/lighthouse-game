# Художественные материалы

В игру попадает только содержимое `public/`. Источники, концепции и история
остаются здесь; само имя `v1` или `v2` не означает, что ресурс устарел.

| Область | Статус |
| --- | --- |
| `game-menu-v2/` | Источник действующих кнопок меню игры |
| `concepts/preparation-2026-11-17/` | Концепции и входы текущих генераторов подготовки; `runtime-v1/` — снимки реализации |
| `concepts/battle-2026-11-18/` | Одобренный дизайн боя; `runtime-v1/` — снимки реализации, `runtime-assets/` — запрос спрайтов |
| `concepts/play-menu-2026-11-17/`, `concepts/settings-2026-11-17/` | Художественные решения экранов |
| `menu-sprites-v1/` | История и сохранившиеся мастера действующих спрайтов меню |
| `chapter1-headland-reference-v1/`, `settings-reference-v2/` | Отдельные художественные референсы, не подключённые к runtime |
| `archive/runtime/` | Заменённые экспорты, исключённые из production |

[ASSETS.md](ASSETS.md) сохраняет происхождение, рецепты, промпты и сведения о
правах. Некоторые исторические источники отсутствуют: их нельзя восстановить
из готовых игровых атласов без потери авторских данных. Перечень ограничений
генераторов — в [tools/README.md](../tools/README.md).
