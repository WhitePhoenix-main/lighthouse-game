# Источники графики меню

Исходные утверждённые референсы пользователя: desktop 1672×941 и mobile 841×1870, сохранены как `floor-desktop-reference.png` и `floor-mobile-reference.png`. `desktop.png` и `mobile.png` получены встроенным imagegen редактированием соответствующих референсов: удалить надписи и фон, сохранить камни, значки и разделитель. Подложки вырезаются из оригинальных референсов многоугольными масками, заданными в скрипте; скрытые кнопками области оставлены прозрачными.

Кадры состояний и вырезки производятся `tools/assets/prepare-game-menu.mjs`; размеры и координаты вырезок указаны в manifest. Desktop-кнопка «Назад» использует очищенный мобильный источник, поскольку при редактировании desktop-референса она пропала.
