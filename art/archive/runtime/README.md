# Заменённые ресурсы интерфейса

Шесть прежних экспортов перенесены из `public/` при реорганизации 18 ноября 2026.
Текущие главное меню и настройки используют общий фон `menu-sprites/`,
настройки — атласы `menu-buttons-v2/`, меню игры — именованные desktop/mobile
кнопки из действующего `game-menu/manifest.json`.

[Манифест](manifest.json) сохраняет прежние пути, размеры и SHA256. Эти файлы
не входят в production. Их происхождение и история сохранены в
[реестре ресурсов](../../ASSETS.md). Рецепты старых экспортов находятся в
`tools/archive/` и пишут в `test-results/archive/`.

Одинаковый PNG маяка для древа удалён из `public/images/skill-tree/`;
древо и мир используют одну копию `public/images/preparation/world/lighthouse-main.png`.
Исходные атласы и художественные концепции сохранены.
