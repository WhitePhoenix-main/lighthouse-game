# Preparation reference pair: shared contract

Рабочие референсы мобильной и настольной подготовки. Не интеграция в игру.
Владелец файлов сборки и PNG — назначенный исполнитель. Root владеет этой
спецификацией, README и общими документами проекта. Дизайнер выполняет read-only review.

## Общие источники и ограничения

- Цвета: ink `#DFC7A2`, muted `#AAB7BE`, background `#08131D`, amber `#E6AC63`,
  lighthouse area `#E9C77D`, fog area `#9BBCCB`.
- Буквы: `../full-screen-v1/glyphs.json`, точный алгоритм меню с Й и `/`.
- Иконки: `../full-screen-v1/ui-icons.png` и `.json`, aspect-preserving contain.
- Основной skin: `../mobile-slate-v3/ui-chrome.png` 953×1651 и source/inset rects
  из `ui-skin-layout.json` той папки. Отдельные nine-slice панели, без растяжения
  всего skin. Обычный камень низкой насыщенности, яркий янтарь у старта.
- Главная, настройки и выбор игры — стилевой эталон. Не менять эти страницы.
  Настройки используют `sprites/menu-buttons-v2`, выбор — `sprites/game-menu`.
- Мир: `../world-v2/scene-data.js/json`, `camera-geometry.js`, terrain и спрайты.
  Один набор объектов и мировых позиций для обоих кадров. Контуры из rules.
  Не использовать запечённую карту старой мобильной иллюстрации.
- Общая художественная калибровка подложки: bounds terrain ×0.75 для ОБОИХ
  видов, как в desktop-cohesion-v2. Это единое предложение масштаба рельефа,
  не независимое приближение фона во время игры. Source/canonical не изменять.
- Десктопный zoom объектов = 0.9001956947162427, как согласованный baseline;
  размеры спрайтов не увеличивать. Мобильный fit настоящих областей с запасом.
- В основной игре всё ещё shoreX=0; новая физическая маска берега здесь не делается.
- Одна карта, общий план. Крупный план только по явной кнопке, без второго viewport.
- Истинные значения примерного профиля прежние:136/3,4 волны,объекты3/4,типы2/2,
  базовая линза,вспышка,две пушки и барьер,декоративный причал. Профиль не читать/менять.

## Мобильный

Canvas780×1688, ориентир CSS390×844 при DPR2. Критичные надписи около14–16 CSS px:
glyph scale3.25 даёт14.625 CSS px. Вторичные подписи допускаются меньше, но
длинную декоративную фразу можно сократить. Не уменьшать все надписи ради вмещения.

Опорная компоновка (уточнить по review, сохраняя приоритет карты):

- Верхний ряд y16..104:Назад,136+,3+. Высота88; отдельные plus hit areas88×88.
- Глава/ночь y122..194:две читаемые строки выбора, без отдельной тяжёлой рамки.
- Улучшения и разведка y211..299:две кнопки по364×88.
- Поле y300..1290:990px,58.6% высоты. Без тяжёлой рамки отдельной картины.
  Фон поля продолжается под полупрозрачными верхней/нижней полосами.
- В верхней свободной зоне поля слева «4 ВОЛНЫ», справа кнопка «КРУПНЫЙ ПЛАН».
  Читаемая легенда света/тумана располагается так, чтобы не заслонять объекты.
- Под полем компактные раздельные лимиты; каталог устройств одной строкой;
  линза/способность на общей каменной полке с двумя зонами; явный старт.
- Старт и подпись о бесплатной расстановке помещаются до нижнего safe margin.
- Пользователь может открыть каталог многих типов; картинка не означает
  фиксированную пару типов. Наличие устройств не рисовать как слоты типов.

## Десктоп

Canvas1672×941. Верхняя цельная полоса≈96px и нижняя≈170px. Один мир на всём
фоне без отдельной карточки карты. Верх:Назад,глава/ночь,валюты с плюсами,
Улучшения,Разведка. Нижний док:Устройства,Линза,Способность,раздельные лимиты,Старт.
Неподвижные props baseline; рельеф в едином масштабе0.75. Мировые области и
маяк/причал должны находиться внутри свободного поля с отступом от панелей.
Постараться уменьшить число отдельных обрамлений, сохраняя ясные действия.

## Воспроизводимость и QA

Сборка хранит layout/camera JSON, источник/night/rules, calibration и hashes.
Проверить glyph bounds, panel containment, icon/sprite aspects, terrain coverage
в видимом поле, одинаковые world coordinates/radii, baseline desktop sprite sizes,
мобильную долю поля, общие palette/art sources. PNG смотреть в native и в
мобильном размере390×844. Это экспорт, не браузер или реальный телефон.
Код игры, зависимости, старые концепты и source PNG не менять.

Выходы: `mobile.png`, `desktop.png`, `mobile-at-390.png` (предпросмотр),
layout/camera/calibration/verification JSON и реальные команды сборки.
