# Книги кампании и испытаний

Шесть визуальных референсов «Света Авалона» от 18 ноября 2026 года. Все PNG
сохранены в исходном размере с прозрачным полем вокруг книги.

| Книга | Состояние | Файл |
| --- | --- | --- |
| Кампания | Разворот, первый лист ночей в сетке 2×2 | [Первый лист](campaign-desktop-sheet-1.png) |
| Кампания | Разворот, второй лист с двумя оставшимися ночами | [Второй лист](campaign-desktop-sheet-2.png) |
| Кампания | Оглавление на правой странице с условием открытия главы | [Оглавление](campaign-desktop-contents.png) |
| Кампания | Портретный экран, один лист с берегом, ночами и перелистыванием | [Мобильная кампания](campaign-mobile-portrait.png) |
| Испытания | Отдельный разворот с выбранным испытанием слева и списком справа | [Книга испытаний](trials-desktop.png) |
| Испытания | Портретный экран с выбранным испытанием над сеткой | [Мобильные испытания](trials-mobile-portrait.png) |

Закладка «Оглавление» меняет содержимое правой страницы. Стрелки под
сеткой перелистывают ночи выбранной главы. На широком экране иллюстрация
главы остаётся слева. В портрете книга показывает одну прокручиваемую
страницу. На референсе второго листа «Ночь 5» и «Ночь 6» служат примерами
расширенной главы. При реализации состав, названия и доступность берутся
из каталога игры.

Отдельная книга испытаний показывает иллюстрацию и цель выбранного
испытания. При количестве записей сверх четырёх к ней применим тот же
принцип перелистывания. На иллюстрациях медная кромка обозначает выбор,
а яркий луч в сетке кампании — пройденную ночь. Внешний фон и кнопки
остаются отдельным этапом оформления.

Создано встроенным ImageGen по собственным материалам проекта. Исходная
форма книги взята из раннего разворота. Палитра и масштаб пикселей сверены
с фоном меню и снимком подготовки. Для испытаний использованы изображения
корпуса и паруса игрового корабля. [Ранний концепт](../arthurian-lighthouse/chapter-night-chronicle-landscape-v2.png),
