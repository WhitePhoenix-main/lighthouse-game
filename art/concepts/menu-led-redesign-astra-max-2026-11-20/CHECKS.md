# Проверка экспортированного комплекта

## Что воспроизведено

На Windows с Python 3.12.14 и Pillow 13.0.0 сборщик разложил каждый из 47 экранов в трёх окнах и четырёх вариантах текста. При экспорте он измеряет чернильные границы каждой строки с учётом тени, Й, Ё и выносных элементов. Перенос использует ширину глифов. Для стрелки перехода в диалогах и карточке покупки выделена собственная пиксельная форма. Итоговые PNG проверяются повторным открытием. [Протокол компоновки](audit/layout.json).

Проверяющий скрипт читает каждый готовый файл. Для ПК он доказывает попиксельное равенство макета удвоенному родному кадру. Для всех окон он проверяет видимые точки края отрисованных кнопок по соответствующему спрайту, полные размеры файлов и неповторяющиеся варианты RU/EN и обычного/крупного текста. Пиксели каждого отдельного прозрачного PNG совпадают с его кадром атласа. Прямоугольники кадров не пересекаются, для каждого 9-slice остаётся растягиваемая середина, у каждого спрайта присутствуют прозрачные и непрозрачные пиксели. Рабочие координаты установленных объектов лежат на суше и в радиусе установки. Отдельный отрицательный пример попадает в воду. [Технический результат](audit/verification.json) · [SHA-256 экспортов](audit/sha256.json).

## Область проверки

Главное меню зафиксировано реальным браузерным стендом. Новые изображения — статические проектные кадры. Пиксельная проверка подтверждает графику, её сборку и границы текста в указанных окнах. Поведение мыши, доступных имён, клавиатуры, касаний, прокрутки и возобновления боя подлежит проверке после интеграции в Phaser. Проверка на физическом телефоне и человеческий плейтест в этот проход не входили.

Для повтора сборки и независимой проверки используйте команды в [README](README.md).
