# Спрайты существ для боя

18 ноября 2026. Встроенный `image_gen.imagegen`, transparent_background=true.
Запрос: [enemy-atlas-prompt.txt](enemy-atlas-prompt.txt). Визуальный вход —
собственный одобренный `../desktop-v1.png`. CLI/API fallback не использовался.

Результат сохранён без редактирования в `public/images/battle/enemies.png`:
1254×1254, настоящий alpha, прозрачный угол A=0. Квадранты: призрак,
минотавр, черепаха, мышь. `public/images/battle/frames.json` фиксирует
непустые области при alpha≥64; эти source-rect используются напрямую,
без обрезки файла. Соотношение сторон каждой фигуры сохраняется.

Это собственная сгенерированная графика по собственному референсу. Новые
сторонние изображения, шрифты и зависимости не использовались.
Спрайты имеют по одному кадру: движения и состояния берутся из симуляции,
полные анимационные циклы не входят в текущий перенос экрана.
