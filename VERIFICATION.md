из отдельного индекса и включает исходные локальные изменения. Сохранены
ветка `beta-02` и её индекс. Глава 7 в статусе визуальной приёмки.

  устройств. Четыре профиля экрана, включая портретный DPR 3. Контрольные
  кадры главной страницы, подготовки, крупного плана и боя первой главы
  совпали попиксельно. Все 12 сочетаний размера окна, языка и текста
  для главы 7 прошли. Проверены положение часов, изменение размера без
  замены попытки, наведение после поворота, сохранение луча при касании
  панели ночи и при открытии команды устройства. Отдельно проверен выбор
  пушки на видимой части карты выше границы поля расстановки.
  [ПК](test-results/visual-pilot-2026-11-20/compare-desktop.png) ·
  [Портрет](test-results/visual-pilot-2026-11-20/compare-portrait.png) ·
  [Альбом](test-results/visual-pilot-2026-11-20/compare-landscape.png)
- Обзор и бой главы 7 имеют одинаковые камеру и позиции объектов:
  zoom 0,780 на ПК, 0,428 в портрете и 0,481 в альбоме. В независимом
  визуальном ревью отмечены остаточная повторяемость поверхности и
  конкуренция полос с мелкими существами. У пассивных частей босса
  во время телеграфа роль считывается преимущественно по силуэту.

  для каждой проверенной пары. На ПК в маршруте главы 7 это 76 путей
  и 4 195 864 байта. За более тонкую фактуру один кэшируемый кадр грунта
  при 1280×720 в бою требует расчётно 2,75 МиБ RGBA8 вместо 0,99 МиБ.

  шаге дал p95 16,9–17,2 мс до и 16,8–17,0 мс после. Это проверка
  устойчивого кадра в эмуляции, время холодного входа и нагрузку
  на физическом телефоне она не характеризует.

## Команды

```powershell
pnpm typecheck
pnpm test
pnpm test:audits
pnpm build
```

Команды определены в package.json; используется pnpm.
CI запускает тесты перед сборкой. Проверки типов и build не заменяют
проверку поведения интерфейса в браузере.

Для готовой сборки запустите pnpm preview и передайте её фактический адрес:

```powershell
node tools/browser/verify-build.cjs http://127.0.0.1:4173/
```

Для экранов запустите pnpm dev, используя фактический адрес Vite:

```powershell
node tools/browser/verify-game-menu.cjs http://127.0.0.1:5173/
node tools/browser/verify-preparation.cjs http://127.0.0.1:5173/
node tools/browser/verify-preparation.cjs http://127.0.0.1:5173/ --layout-only
node tools/browser/verify-skill-tree.cjs http://127.0.0.1:5173/
```

У инструментов различаются способы подключения к Chrome.
Часть использует внешнюю зависимость Playwright: LIGHTHOUSE_PLAYWRIGHT_PATH
задаёт модуль, LIGHTHOUSE_BROWSER_PATH — браузер. Другие используют Chrome
DevTools Protocol и изолированный профиль. Fixtures в tests/browser/
используют хранилище в памяти. Результаты создаются в test-results/.
