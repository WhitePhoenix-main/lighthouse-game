# Маяк — Туманный берег

> A browser-based lighthouse defense game. Hold back waves of monsters with a
> beam of light, build defenses, and unlock upgrades.

Локальный прототип на Phaser 3, TypeScript и Vite. Три обычные ночи первой главы,
испытание корабля, босс с тремя уровнями и первая ночь второй главы;
восемь линз, призраки, черепахи, минотавры и летучие мыши,
две цели луча, поворот 90°/с, более плотные волны, ранний вызов, локальные награды
и постоянное развитие маяка: ночь → награда → улучшение → подготовка и ремонт → новая попытка.

Есть главное меню «Свет Авалона» по художественным референсам, отдельные развитие
и подготовка, настройки текста, языка, музыки и эффектов, бой,
пауза и результат. План дальнейших работ — [ROADMAP.md](ROADMAP.md).

Музыка меню запускается при открытии страницы. Если браузер блокирует автозвук,
запуск повторяется при первом клике, касании или нажатии клавиши. В настройках доступны
её громкость и общее выключение звука; при потере активности воспроизведение
приостанавливается. Главное меню использует один пиксельный пейзаж 640×640 для
компьютера и обеих ориентаций телефона. Фон и декор представлены отдельными PNG-слоями,
минутная музыка MP3 занимает 721 КБ. Название быстро проигрывает спрайтовую
анимацию и замирает. Вода, трава и облака оживляются в исходных местах; корабль
неподвижен, его огни мерцают. Небольшая носовая волна и короткий след из восьми
кадров связывают корпус с водой; ватерлиния мягко сведена к прозрачности. Ореол маяка уменьшен и смягчён, пять окон медленно
загораются в случайном порядке; над дальним берегом дрейфует лёгкий туман.
В `dist/` входят подготовленные ресурсы из
`public/`, исходные референсы из `art/` не копируются.
Источники и команды подготовки — [art/ASSETS.md](art/ASSETS.md).

## Запуск

Нужны Node.js 22.12+ (проверено на 24.22.1) и pnpm 11 (проверено на 11.25.0).
Проект использует **pnpm**: версии закреплены в `pnpm-lock.yaml` и поле `packageManager`.
Если в вашем PowerShell команда `pnpm` не найдена, сначала установите её:

```powershell
npm install -g pnpm@11.25.0
```

В PowerShell из папки проекта:

```powershell
cd E:\WebGames\Lighthouse
pnpm install --frozen-lockfile
pnpm dev
```

Открыть адрес, напечатанный Vite, обычно http://127.0.0.1:5173/.
Если порт занят, Vite выбирает следующий. Для удобства держите один и тот же
адрес: localStorage привязан к origin, включая имя хоста и порт.
`index.html` нельзя запускать как файл: игре нужен локальный HTTP-сервер.

```powershell
pnpm typecheck
pnpm test
pnpm build
pnpm preview
```

`build` создаёт `dist/`; `preview` показывает production-сборку, обычно на порту 4173.
В `vite.config.ts` настроен относительный базовый путь `./`: одна сборка работает
и в корне локального preview, и в каталоге опубликованного сайта.
Если в консоли появился 404 для `/Lighthouse/assets/...` после прежней сборки
с `--base=/Lighthouse/`, выполните `pnpm build` и обновите страницу preview
по корневому адресу, напечатанному Vite. `preview` сам не пересобирает `dist/`.
Браузерная проверка готовой сборки: `node tools/verify-build.cjs <адрес-preview>`.
Можно передать несколько адресов; проверяются скрипт, стили, шрифт, изображения
и переход в настройки. Как и у `tools/verify-menu.cjs`, Playwright задаётся через
`LIGHTHOUSE_PLAYWRIGHT_PATH`, путь к тестовому браузеру — `LIGHTHOUSE_BROWSER_PATH`.
Lock-файл фиксирует реальные версии. `pnpm-workspace.yaml` хранит кеш внутри проекта
и разрешает необходимый postinstall только esbuild.

### Если `npm i` завершился ошибкой ERESOLVE

В уже установленной папке pnpm зависимости связаны через `node_modules/.pnpm`.
В наблюдавшемся сбое npm пытался разрешать зависимости разработки этих пакетов
(Jest, ts-jest, TypeDoc и другие), которых нет среди зависимостей самого «Маяка».
Восстановите дерево выбранным менеджером по существующему lock-файлу:

```powershell
pnpm install --frozen-lockfile
pnpm dev
```

После приведённого сбоя эта команда успешно проверена; удалять `node_modules`
не потребовалось. `--force` и `--legacy-peer-deps` для восстановления не нужны.
Способ установки pnpm описан в [официальной инструкции](https://pnpm.io/installation/).

## GitHub и тестовая публикация

Исходники можно хранить в GitHub и разрабатывать изменения в отдельных ветках.
Для GitHub Free публикация из того же репозитория требует, чтобы он был публичным:
все отправленные исходники, материалы и история станут доступны другим людям.
Для приватного проекта можно отдельно опубликовать собранную игру в публичном
репозитории. Подробнее — в [документации GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages).

В коммит обязательно должен входить скрытый каталог `.github/`, в частности
`.github/workflows/deploy-pages.yml`. Одного наличия файла на компьютере недостаточно:
проверьте его на вкладке **Code** репозитория.

После загрузки проекта в репозиторий откройте **Settings → Pages** и выберите
**Build and deployment → Source → GitHub Actions**. Процесс
`.github/workflows/deploy-pages.yml` устанавливает зависимости по lock-файлу
и собирает игру в pull request. После отправки изменений в `main` отдельный этап
публикует только `dist/`. Права публикации выдаются только этому этапу. Процесс также
запускается вручную из **Actions → Deploy preview to GitHub Pages → Run workflow**
для `main`. Если первая сборка была запущена до настройки Pages, после выбора
GitHub Actions запустите процесс вручную.

Если в Actions запущен **pages build and deployment** с этапом **Build with Jekyll**,
публикуются исходники без компиляции Vite. Для этой игры выберите источник
**GitHub Actions** и дождитесь **Deploy preview to GitHub Pages**: сначала
`build` (установка зависимостей и `pnpm build`), затем `deploy`.

Рабочие ветки сами по себе сайт не обновляют: после проверки создайте pull request
и объедините его с `main`. Адрес обычно имеет вид
`https://USERNAME.github.io/REPOSITORY/`; итоговая ссылка появится в настройках
Pages. Сайт остаётся доступным, пока публикация не отключена. Прогресс сохраняется
в браузере посетителя и не переносится автоматически с локального адреса.

## Как играть

В меню нажмите «Начать» (новый профиль) или «Продолжить» (сохранённый профиль).
Откроется подготовка, затем нажмите «Начать ночь». Прогресс не сбрасывается;
«Продолжить» в меню не восстанавливает бой после перезагрузки.
Мышь направляет луч движением над полем. На сенсорном
экране коснитесь поля или ведите пальцем; после отпускания направление остаётся.
Свет постоянный, дальность отмечена пунктиром. Тёплая обводка отмечает выбранные
цели, насечки показывают реальный урон, голубые сколы — разрушение брони,
затухающий контур — гибель. До двух доступных целей получают
полный урон. Полностью закрытая другим существом цель помечается «Перекрыт».
Черепаха сначала теряет голубую броню, затем здоровье; повреждения брони сохраняются.

Суша слева, море справа, граница проходит через маяк. Устройства ставятся целиком
на суше. Черепаха и минотавр выходят с суши, призрак и мышь — с обеих сторон.
Минотавр заметно готовит один усиленный рывок, мышь ищет ближайшее устройство
и игнорирует барьеры; обычные пушки мышь не поражают. Дальние корабли декоративные.
Счётчик «За ночь» показывает временные осколки и бонус; он отделён от сохранённого
баланса. В бою видны число начатых и число отражённых волн.

Кнопка досрочного вызова запускает следующую волну поверх текущей. Бонус нужно
заслужить: он начисляется после уничтожения всей вызванной волны. Следующая волна
сама выходит по таймеру, даже если предыдущая ещё жива. Уничтожьте всех и сохраните маяк.
Добравшиеся до маяка враги остаются и атакуют. Между волнами здоровье не восстанавливается.

Esc или кнопка паузы останавливает ночь. Потеря фокуса и сворачивание также ставят
паузу; после возвращения нажмите «Продолжить». Поворот экрана сохраняет бой.
После сохранённого результата выберите подготовку, развитие или главное меню.
При ошибке результат удерживается до успешного повтора записи.
Из паузы можно открыть настройки и вернуться в ту же паузу. «Прервать ночь»
запрашивает подтверждение, отбрасывает временные награды/встречи и сохраняет
состояние устройств на старте. Покупки и ремонт подготовки не возвращаются;
выход в меню/подготовку выполняется после записи. Старые активные попытки v1–v4
при миграции получают прежний возврат аренды один раз.

На отдельном экране «Развитие маяка» покупайте улучшения за сохранённые осколки.
Его можно открыть из подготовки и сохранённого результата; «Назад» ведёт в источник.
Три исходные ветви
(мощность, ширина, дальность) содержат по две ступени; вторая требует первую.
Дерево показывает баланс, текущие характеристики, изменение после покупки,
цены и причину недоступности. Выберите узел, прочтите сведения и нажмите покупку.
Узлы доступны мышью, клавиатурой и касанием. На коротком экране панели прокручиваются;
«Разведка: состав волн» раскрывает сведения о ночи. Масштабирование дерева не нужно.
Награды незавершённой ночи тратить нельзя. Купленные узлы постоянны, применяются
к новой попытке; характеристики уже начатого боя зафиксированы.

Текущее дерево содержит **122 покупки**: 82 основных узла и узла устройств,
33 улучшения линз, семь платных открытий линз. Это семь шагов к согласованным
200. Добавлены поворот до 100°/с, прочность маяка, поле, вспышка, развитие пушки,
гарпун, мортира, колокол, ремонтный фонарь, базовая, фокусирующая, тлеющая,
резонансная и дальнобойная линзы. Старые покупки, цены, эффекты и сохранения
совместимы; обновление не выдаёт новые покупки автоматически.

В этапе 4 исходное дерево содержало 14 узлов в 6 ветвях: открытия устройств,
вспышки, третий/четвёртый слот типов и «Связанный свет». Последний требует
мощности I и ширины I и добавляет 20% урона каждой из двух реально освещённых
враждебных целей. Корабль бонус не включает. Цены и условия видны у выбранного
узла; все ветви можно открыть повторными наградами.

В меню, подготовке и сохранённом результате можно выбрать ночь. Победы открывают
цепочку «Первый свет» → «Разбитый берег» → «Крылатый прилив» → «Страж глубин».
Первая победа во всей ночи босса открывает главу 2 «Дальний берег» с одной обычной ночью.
Повтор открытой ночи бесплатен и даёт обычные награды, даже при поражении.
Поэтому нулевой баланс не закрывает путь к развитию. Смена ночи сохраняет
принадлежащие игроку устройства и расстановку; в бою и паузе смены нет.

После первой победы доступен отдельный «Сигнал бедствия»: накопите 6 секунд света
на корабле за первые 24 секунды боя. Он занимает одну цель луча и участвует
во взаимном перекрытии с существами. Прогресс сохраняется при переключении.
Спасение даёт 12 временных осколков, сохраняемых при обычном исходе и теряемых
при прерывании. Потеря корабля не проигрывает ночь; испытание не открывает обычные
ночи. Его включение в будущий релиз ещё оценивается плейтестом.

## Оснащение и линзы

В подготовке выберите одну открытую линзу. Выбор бесплатный, до начала боя остаётся
черновиком; успешный старт сохраняет его вместе с записью попытки. В бою и паузе
линза фиксирована. Линзы и их собственные узлы покупаются отдельно на экране развития.

| Линза | Цена жемчуга | Урон / ширина | Целей | Особенность |
| --- | --- | --- | --- | --- |
| Базовая | 0 | ×1 / ×1 | 2 | Без дополнительных эффектов |
| Расширенная | 2 | ×0.85 / ×1.6 | 3 | Четыре узла: +8° ширины, четвёртая цель, +2/+2 урона |
| Замедляющая | 3 | ×0.8 / ×1 | 2 | Скорость выбранных целей ×0.6; узлы: ×0.45, +6 урона/с, +15 дальности, ещё +3 урона/с |
| Противоброневая | 3 | ×0.8 / ×0.7 | 1 | Урон броне ×2; узлы: ×2.5, +6 урона/с, +4° ширины, ещё +8 урона/с |
| Фокусирующая | 3 | ×1.5 / ×0.75 | 1 | После 1.5 с удержания одной враждебной зоны ещё +10% урона |
| Тлеющая | 3 | ×0.7 / ×1 | 2 | 6 урона горения/с, ещё 2 с после потери света; без сложения |
| Резонансная | 3 | ×0.9 / ×1.1 | 2 | После 2 с непрерывного освещения пары ещё +25%; потеря пары сбрасывает бонус |
| Дальнобойная | 3 | ×0.8 / ×0.8 | 2 | Дальность ×1.15; четыре узла: +4/+4 урона, +2°/+2° ширины |

Базовая линза имеет пять узлов: мощность I/II (+3/+3), ширина (+2°), дальность
(+10) и парный свет (+10% при двух целях). Фокусирующая — четыре: мощность (+4),
дальность (+15), удержание I/II (+5%/+5%). Удержание сбрасывается при потере света
или переключении, включая переход между щупальцами. На корабле не накапливается.

Базовая дальность прежняя. Первые два узла каждой из трёх прежних особых линз последовательны и предварительно стоят
45 осколков + 1 жемчуг и 70 + 2. Полное перекрытие и предел целей сохраняются;
эффекты не работают на закрытых или не выбранных врагов. Бонус к броне не
умножает урон здоровью. С замедлением щупалец применяется сильнейшее замедление.

Гарпун открывается после «Крылатого прилива» и открытия пушки за 70 осколков,
первый экземпляр выдаётся бесплатно. Дополнительный стоит 36, полный ремонт 9.
Он стреляет и по летающим врагам: 14 урона раз в 1.4 с, дальность 200, HP 60;
три узла повышают урон до 18, дальность до 225 и сокращают интервал до 1.2 с.
Новые цены и эффекты предварительны; подробная таблица — в GAME_DESIGN.md.

Мортира открывается после «Крылатого прилива» и пушки за 95 осколков с первым
экземпляром. Следующий стоит 48, полный ремонт 12. Снаряд летит к зафиксированной
точке и взрывается по нелетающим врагам: 24 урона раз в 3 с, дальность 230,
радиус взрыва 55, скорость 180. Семь улучшений доводят урон до 36, интервал до
2.6 с, радиус до 75, скорость до 270 и урон броне до ×1.5. Быстрый враг может
уйти из взрыва; союзники не получают урон.

Тлеющая линза получает четыре узла: +3 прямого урона, +2/+2 урона горения и
+1 с его длительности. Горение сначала повреждает броню, не считается
освещением и не подавляет щупальца. У босса один эффект на общее здоровье;
каждый взрыв мортиры также повреждает его один раз. Пауза останавливает полёт
снарядов и горение. Сохранения перенесены в v6; новые открытия автоматически не выдаются.

Колокол сдерживания открывается за 85 осколков после барьера и «Крылатого прилива».
Первый корпус входит в открытие, следующий стоит 40, полный ремонт 10. Импульс
радиуса 140 раз в 6 с замедляет движение врагов до ×0.65 на 1.5 с, без урона
и подавления атак. Семь улучшений дают радиус 170, срок 2 с, интервал 5.5 с,
защиту корпуса ×0.8 входящего урона и первый импульс за ночь со скоростью ×0.5.
Защита не чинит корпус и не меняет максимальное HP. При пересечении со светом
или другим колоколом действует сильнейшее замедление, без перемножения.

У резонансной линзы четыре узла: +4 урона, +4° ширины, +10/+10 процентных пунктов
бонуса. Считаются реально выбранные враждебные зоны, включая отдельные щупальца;
корабль не считается. Пара может менять состав, пока обе цели остаются в свете.
Резонанс складывается со «Связанным светом». Он полезен при устойчивой паре,
а короткое освещение слабее базового. Сохранения перенесены в v6, прежние покупки
и повреждения сохранены. Числа предварительны, требуется живой плейтест.

Ремонтный фонарь открывается после генератора и босса за 110 с первым корпусом.
Следующий стоит 48, полный ремонт 12. Три заряда по 10 HP, интервал 6 с,
дальность 140. Чинит другие живые устройства только до их здоровья на старте
ночи; старые повреждения требуют платного ремонта. Не чинит фонари, маяк,
щит и израсходованные ловушки, не воскрешает и не перезаряжает. Семь узлов
дают 20 HP за заряд, пять зарядов, дальность 170, защиту корпуса ×0.8 и один
двойной аварийный ремонт при HP цели ≤25%. Он тратит обычный заряд; общий
бюджет полной ветви не выше 120 HP. Итог ремонта сохраняется при победе и
поражении; перезапуск не лечит старые повреждения. В новой ночи заряды свежие.

Дальнобойная линза даёт 345 дальности вместо 300 ценой 20% урона и ширины.

## Ночь босса и материал

Щупальца «Стража глубин» — отдельные цели с общей полосой здоровья. Луч повреждает
каждое выбранное щупальце, замедляет его и останавливает его атаки. Вспышка оглушает
всего босса; её урон и взрыв ловушки учитываются один раз по общему здоровью.
Пушки тоже могут целиться в щупальца через меню. После гибели босса нужно отбить
оставшиеся волны. Обычное поражение после его гибели сохраняет обычные ресурсы,
но не выдаёт материал и не открывает следующую главу.

Победы во всей ночи дают 2/3/4 «Жемчуга глубин» на уровнях 1/2/3.
Только такая победа повышает следующий уровень; после уровня 3 можно продолжать
повторы с наградой 4. Поражение и прерывание уровень не меняют. Предварительные
HP: 420/600/780, щупальца: 3/4/5. Жемчуг тратится на линзы и их мини-деревья,
учитывается отдельно от обычных осколков. Покупки не усложняют обычные ночи.

## Расстановка

Открытие типа в дереве выдаёт первый постоянный экземпляр. Дополнительные
покупаются отдельной кнопкой. Выберите тип с готовым экземпляром в запасе,
затем нажмите на карту. Два слота типов развиваются до четырёх; на поле до
четырёх объектов, не более двух каждого типа. Предпросмотр проверяет берег и пересечения.

Кнопка «В запас» снимает объект с поля без продажи, «Все устройства в запас»
освобождает расстановку. Позиции, прочность и заряды сохраняются между экранами,
ночами и перезагрузками. Старт и перестановка бесплатны даже при нулевом балансе.

Инвентарь показывает прочность и стоимость восстановления. Полный ремонт
стоит не более 25% цены: пушка 5, барьер 3, генератор 7, ловушка 4 осколка.
Частично повреждённый корпус ремонтируется дешевле, до целого осколка вверх,
с ограничением полной цены ремонта. Перезарядка ловушки отдельно
стоит 10% цены с округлением вверх за каждый недостающий заряд — 2 осколка,
до 4 за пустую двухзарядную. Ремонт не даёт заряд,
перезарядка не чинит корпус. Неработающие объекты можно оставить на поле, но
они занимают слот и место; разрушенный генератор не создаёт щит.

Черепахи останавливаются у встретившихся пушек/барьеров и разрушают их; призраки
проходят через барьеры, но атакуют пушки. После разрушения существа продолжают путь.
В бою устройства неподвижны; новых установок нет. Боевой ремонт выполняет
ремонтный фонарь в пределах стартового здоровья, без пополнения зарядов.
Прочность устройств видна под ними, выстрелы отмечены коротким следом.

Генераторы поддерживают одно поле вокруг маяка: голубая граница в подготовке
показывает защищённую зону. Устройство защищено, когда целиком внутри неё.
Второй генератор удваивает запас, скорость восстановления остаётся общей.
Попадания по полю, а при его истощении — по защищаемым целям сбрасывают задержку.
Состояние и оставшееся ожидание видны под полем боя. Восстановившийся щит
выталкивает врагов; потеря последнего генератора отключает поле.

«Вспышка» наносит урон и на время останавливает движение и атаки врагов рядом
с маяком. Кнопка показывает время до готовности. Новые профили открывают её
через дерево после второй победы, старые сохраняют доступ.
Ловушка автоматически расходует заряд при приближении
врага; со вторым зарядом может сработать ещё раз не раньше чем через 2.5 с, наносит урон по области без оглушения; расход показан отдельно от разрушения.

Нажмите на устройство на поле или его кнопку в списке, чтобы открыть меню.
Пушка принимает автоприоритет (ближайший / самый сильный / самый слабый) и конкретную
цель с поля или списка. Пока закреплённая цель вне дальности, пушка ждёт; гибель
цели или «Сбросить в авто» возвращает автоматический выбор. Сила — здоровье + броня.
Бой идёт при открытом меню, луч сохраняет направление до закрытия. Esc сначала
закрывает меню, следующее нажатие ставит на паузу. Остальные устройства имеют
информационные меню: они работают автоматически.

## Сохранения

Прогресс автоматически сохраняется в localStorage (`lighthouse.save.v1`). Обычная
победа и поражение сохраняют ресурсы за убийства и заслуженные бонусы. Обновление
страницы во время боя считается прерыванием: временная награда и новые встречи
отбрасываются, прежний профиль остаётся. Пауза без перезагрузки ничего не отбрасывает.
Новые попытки бесплатны; оплаченные покупки, ремонт и перезарядка подготовки
сохраняются. Однократный возврат аренды действует только для старых попыток.

JSON обновлён до **версии 6**, ключ остаётся **`lighthouse.save.v1`**.
Миграция v1–v5 сохраняет ресурсы, покупки, встречи, число и уникальные победы,
данные босса и линз. Для v1/v2 прежнее положительное число побед означает
прохождение только первой ночи; прежние четыре типа и вспышка сохраняются.
Для версий до v4 новые поля босса/линз получают прежние значения по умолчанию,
победа над боссом не выдумывается.

При переносе v1–v4 каждый уже открытый тип получает один исправный заряженный
экземпляр в запас. При переносе v5 инвентарь сохраняется без выдачи новых тел;
старый расход превращается в точный остаток 0 или 1.
Новая схема хранит устойчивые ID, позиции, здоровье, заряд и снимок попытки.
Повторная миграция не выдаёт экземпляры снова. Старые активные попытки возвращают
арендную стоимость один раз. Новые попытки бесплатны: победа/поражение сохраняют
повреждения и расход заряда, прерывание оставляет состояние на старте.

Открытие типа и выдача экземпляра, покупка, ремонт, перезарядка и результат
сохраняются согласованно. При ошибке изменения не объявляются успешными;
«Повторить сохранение» повторяет ту же операцию без двойного списания/выдачи,
включая неопределённый ответ адаптера. Старое дерево и награды пока прежние.

Одна вкладка удерживает Web Lock. Вторая вкладка того же origin не может запустить
ещё одну игру. При ошибке сохранения видны причина и кнопка повтора; результат
нельзя закрыть до успешной записи. Повреждённые и неизвестные версии не сбрасываются.
Режим приватного просмотра и очистка данных браузера не гарантируют сохранность.
Используйте современный браузер на localhost; Web Locks обязательны.

Настройки размера текста, общего звука, громкости музыки и эффектов, языка
`auto` / `ru` / `en` сохраняются отдельно в
`lighthouse.settings.v1` (JSON v3, чтение прежних v1/v2), отдельно от профиля JSON v6 и без создания
нового игрового прогресса. При ошибке доступен повтор или чтение сохранённого
значения; неподтверждённая настройка не объявляется сохранённой. Повреждённые
настройки показывают ошибку и не перезаписываются автоматически.

Настройки используют готовый фон и атлас кнопок главного меню. Прозрачное
затемнение оставляет пейзаж видимым; круглые яркие бегунки, надписи и выбранные
значения рисуются независимо от фона. Горизонтальная и вертикальная компоновки
сохраняют нативные кнопки и ползунки с областями нажатия не меньше 44 px.
На коротком или узком экране настройки прокручиваются. Язык переключает текущие экраны,
описания и сообщения сразу; без SDK автоматический выбор следует языку браузера.
Громкость эффектов управляет процедурными сигналами UI и боя, общий выключатель
сохраняет выбранные уровни. Тембры и громкость пока предварительные.

Проверка нового экрана: `node tools/verify-settings-screen.cjs` при запущенном
Vite на `http://127.0.0.1:5186` (адрес можно передать аргументом). Нужны Node.js 22+
и Chrome; другой путь задаётся через `LIGHTHOUSE_BROWSER_PATH`. Проверка использует
изолированный профиль Chrome и хранилища, сохраняет снимки и отчёт в `test-results/`.
Она проверяет размеры, мышь, клавиатуру, эмулированные касания, перевод,
сохранение/ошибки, перезагрузку и возврат в боевую паузу. Это эмуляция браузера,
не проверка физического телефона. Внешний Playwright для этого инструмента не нужен.

угрозы. Расписания и ограничения проверок — в [GAME_DESIGN.md](GAME_DESIGN.md).

Облака, SDK и монетизации пока нет. Боевая графика создана процедурно;
главное меню использует сжатые художественные референсы и пользовательскую музыку.
Источники и сведения о правах — [art/ASSETS.md](art/ASSETS.md).
Phaser — MIT, Vite/Vitest/TypeScript и транзитивные зависимости сохраняют собственные
лицензии в установленных пакетах. Это локальный прототип, не публикация на площадке.
Production JS пока содержит Phaser целиком (~375 КБ gzip); оптимизация загрузки отложена.

Подробнее о проверках — [VERIFICATION.md](VERIFICATION.md).
Для плейтеста без подсказок подготовлен [PLAYTEST.md](PLAYTEST.md).
Синтетические замороженные сцены для визуальной проверки доступны при `pnpm dev`
по пути `/tests/browser/`; в production-сборку и постоянный профиль они не входят.
Справка инструментов: [Vite](https://vite.dev/guide/),
[Phaser Scale](https://docs.phaser.io/phaser/concepts/scale-manager),
[Phaser Input](https://docs.phaser.io/phaser/concepts/input).
