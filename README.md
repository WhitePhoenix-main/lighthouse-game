# Свет Авалона

Браузерный прототип защиты маяка: игрок направляет луч, выбирает угрозы,
вызывает волны досрочно и развивает оснащение между ночами.
Стек — Phaser 3, TypeScript и Vite. Основная площадка — Яндекс Игры;
подключение SDK и публикация требуют отдельной задачи.

В кампании семь карт, 56 сюжетных ночей, 256 покупок и пять способностей.
Подготовка и бой используют общую геометрию суши. Локальный профиль хранит
прогресс, постоянные экземпляры устройств и активную попытку.
Расписания, контуры и боссы пока предварительные. Дальнейшие этапы описаны в ROADMAP.

## Запуск

Нужны Node.js 22.12+ и pnpm 11.25.0, закреплённый в package.json.
Из корня проекта:

```powershell
pnpm install --frozen-lockfile
pnpm dev
```

Откройте HTTP-адрес из вывода Vite, обычно http://127.0.0.1:5173/.
По этому адресу открывается [кампания](docs/CAMPAIGN_RUNTIME.md).
Запуск index.html с диска не поддерживается. Хранилище привязано к origin,
включая хост и порт. Чтобы продолжить ранее начатую кампанию, используйте
тот же браузерный профиль, хост и порт.
Для защиты профиля от одновременной записи приложение использует Web Locks.

## Проверки и сборка

```powershell
pnpm typecheck
pnpm test
pnpm test:legacy:baseline
pnpm test:audits
pnpm build
pnpm preview
```

build создаёт dist/; preview показывает уже собранный результат.
Сборка использует относительную базу ./; GitHub Actions выполняет тесты перед
сборкой, проверяет исходный список ошибок legacy и балансовые аудиты;
публикация из main загружает только dist/.
Браузерные инструменты находятся в tools/browser/, подготовка ресурсов —
в tools/assets/. Их зависимости и команды описаны в [проверках](VERIFICATION.md).
